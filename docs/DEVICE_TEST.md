# 第一次上机（Mac + Mixxx）

这些在云端 / 模拟器里都无法验证，需要在真机上逐条确认。每一步做完把输出发给 Claude。

## 0. 安装并体检

按 README 安装后：

```bash
~/.venvs/djstudio/bin/djstudio doctor
```

预期：ffmpeg ✓、Mixxx 曲库 ✓、IAC 总线 ✓。「Mixxx 曲库目录」若报错，在 Mixxx 偏好设置 → 曲库里添加 `~/Music/DJStudio`。

## 1. 放进曲子和打碟谱（验收：RW2023 的 14 首 + 《CDW 技法实战 set 打碟谱》）

1. 网页「开始」页：把 14 首和打碟谱 PDF 一起拖进去。打碟谱一栏应显示「14 首都在」，每首对上一个文件。
2. 点「开始分析」，一个进度条走完 6 步。中间会退出并重启 Mixxx（开启「启动时重新扫描」），再逐首静音装进 deck 让 Mixxx 分析。
   - 要验证：重启后托管曲库的歌是否进了 Mixxx 库；装载能否触发分析；分析结果是否写回库；网格校正（RW2023 预计 8 首）写库后 Mixxx 是否认。
3. 「可以演出了」之后看「高级 → 曲库」：每首应是「Mixxx ✓」，没有「网格存疑」。

## 2. 映射 + 真机探测

1. 「同步」或「准备」会把 `DJStudio.js` / `DJStudio.midi.xml` 部署到 Mixxx 的 controllers 目录。
2. 准备时会自动把 mixxx.cfg 里 IAC 总线的映射换成 DJ Studio（沿用原来 AgentMCP 用的设备）。若日志提示找不到 IAC 设备，就在 Mixxx → 偏好设置 → 控制器 → IAC 总线：映射选 **DJ Studio**，勾「启用」。右上角应显示「引擎在线 0.4.0」。
3. 往 deck1 拖一首已分析的歌（不播放），把播放位置拖到曲中，然后在「体检」页点**真机探测**（或 `djstudio probe`）。

Mixxx 的行为已经按 2.5.6 源码逐条核对过（见 [MIXXX_NOTES.md](MIXXX_NOTES.md)），探测在真机上再确认一遍：

| 检查 | 不通过时 |
|---|---|
| SysEx 双向（Python→引擎 需要 XML 里的 0xF0 绑定） | 映射没换成 DJ Studio / 不是 0.4.0；准备时会自动改 mixxx.cfg |
| CC 备用传输 | 仅备用 |
| EQ / 滤波 / 效果单元控件能写能读 | 效果单元里没放效果，或 Mixxx 版本不同 |
| `bpm` 控件可写 | 版本不同 |
| 网格解码（对照 Mixxx 自己的 `beat_distance`） | 把结果发给 Claude |
| 推子模式 = 加性、deck 朝向左/右 | 引擎 init 没跑 |

听感项（探测测不了）：推子居中时两边音量是否一样；echo / reverb 是否挂在对的 deck。

## 3. 第一次播放

1. 先做一套短 set（3 首、两段过渡）：Set 页新建，或把 Claude 生成的 JSON 粘贴进去。
2. 演出页 → 准备（约 1 分钟）→ ▶ 开始。
3. 要验证：
   - AutoDJ 装载：没有误播、推子归中、装载后身份核对通过；
   - 过渡：B 准时起播（日志「B 起播（晚了 x 拍）」应 < 0.1）、没有「相位校正」刷屏、没有「小节错位」；
   - EQ / 滤波 / 推子曲线听感；echo / reverb 是否挂在对的 deck；
   - 演出页的旋钮 / 推子 / 电平和 Mixxx 自己窗口里的一致（同一时刻对照看几次；网页读的是同一批控件）；
   - 主输出电平：长交接两首满音量叠加时不应长时间顶红（体检里 ReplayGain 应为「已开启」）；
   - 淡出停止。
4. 日志在 `~/DJStudio/logs/`，整份发给 Claude。

## 4. 故障注入（可选）

播放中退出 Mixxx：网页应在 2 秒内报「引擎失联」，conductor 停发命令，60 秒后报错停止。

## 假设表（模拟器 / 测试台验证不了，靠真机和耳朵）

| 假设 | 依据 | 怎么核对 |
|---|---|---|
| 谱上 EQ 钟点位 → dB：12 点 0、10 点 -6、9 点 -11、8 点 -18、7 点 -25 dB | 谱：「7 点＝全切（-25 dB）」「B LOW 给到一半」写 10 点；中间按幂曲线（`plan/convert.py` 的 `eq_db`） | 同一段过渡分别在 Prime 4+ 上照谱拧、和 Mixxx 自动跑，听低频交接的深浅；不对就改 `EQ_TAPER` |
| 谱上「推子 5」= Mixxx 推子 50%（-10 dB） | Mixxx 推子曲线（`ControlAudioTaperPot(-20, 0, 1)`）；Prime 4+ 的推子曲线没查到 | B 半推子进场时的音量和 Prime 4+ 比 |
| 谱上 Filter「左 / 右 N 点」= Mixxx QuickEffect 滤波旋钮同一位置 | 位置对位置；两边滤波器的截止频率曲线不同 | 听「左 9 点（切一半）」是否差不多 |
| Main FX Reverb Wet/Dry 1/3 = Mixxx 效果单元 2 的 mix 0.33 | 位置对位置；混响本身不同 | 听尾巴 |
| #06 Key Lock 关（音高 +0.8 半音） | Mixxx keylock 的延迟会让叠放出双击（测试台实测 17–29ms） | 觉得音高不能接受就把 set 的 keylock 打开，同时听过渡里有没有双击 |
| Mixxx ReplayGain 开着 | Mixxx 默认开；关着时两首满音量叠加会削波 | 体检「ReplayGain」一项 |
| 谱上「第 1 小节第 1 拍」秒数和 Mac 上 Mixxx（CoreAudio 解码 MP3）一致 | 谱按文件时间写；解码器的编码延迟处理可能差几十毫秒，只影响吸附到哪一拍（容差 ±0.2 拍） | 生成 set 时的提示里没有「可能对到了别的拍」 |
