# 效果套路示例

- 规范：v5
- 主速：132

> 这份谱只为了演示「效果怎么写」：两首歌、一次交接，把 RMX-1000 上常用的几手（Trans、Roll、Release、HPF Echo、Noise、Spiral、
> 打击垫采样）和发送效果（Echo、Reverb）各写了一处，每一处都是《曲谱规范 v5》第 8.7 节里的套路，可以整行抄走改位置。
> 参数是量过的（docs/V5_G0.md「效果听不听得出来」）：每一手在一段满的 groove 上都比不加效果差出 −7 到 +3 dB，听得出来、又不盖过音乐。
> 文件名是随便起的：换成你自己的两首歌、把素材表里的 BPM / 小节数改对，就能放。

## 场景 1：第一首独奏，句尾加花（1.1 – 49.1）

- 作用：第一首自己走；每 16 小节的句尾用一手效果做记号，不动编排
- 保留：D1 的全部声部
- 前景：D1 主曲
- LOW：不交接，只有 D1 一个低频
- MID/HIGH：不动 EQ
- 角色：D1 主曲

### 效果

| ID | 类型 | 路由 | 目标 | 开始 | 结束 | 参数 | 说明 |
|---|---|---|---|---|---|---|---|
| F1 | Echo | 发送 | C1 | 16.1 | 17.1 | 拍长 1/2拍；送出 1/2；反馈 0.6 | 句尾回声：最后一小节送一半进回声，下一句的开头还听得到它的尾巴 |
| F2 | Trans | 插入 | C1 | 31.1 | 33.1 | 周期 1/4拍；占空 1/2；深度 1 | 句尾两小节把整路切成十六分音符的门，第 33 小节第 1 拍放开 |
| F3 | Roll | 插入 | C1 | 48.1 | 48.3 | 拍长 1/2拍 → 1/4拍 | 进下一段前的两拍越切越碎 |
| F4 | Release | 插入 | C1 | 48.3 | 49.1 | 方式 Echo；回原声；拍长 1/2拍 | 后两拍把 Roll 收成一串渐弱的回声，下一小节第 1 拍回到原声 |

## 场景 2：交接（49.1 – 97.1）

- 作用：第二首切着低频进来，第 81 小节换低频，第一首带着高通回声退场
- 保留：D1 的主题到第 81 小节
- 前景：第 81 小节以后是 D2
- LOW：第 81 小节第 1 拍同一拍对换（D1 切到底，D2 回中）
- MID/HIGH：D1 的中高频不用手退：最后 8 小节交给 HPF Echo 一路扫上去
- 角色：D1 出曲，D2 进曲
- 有意：中频叠加

## 场景 3：第二首独奏，收尾（97.1 – 145.1）

- LOW：不交接，只有 D2 一个低频
- MID/HIGH：不动 EQ
- 角色：D2 主曲
