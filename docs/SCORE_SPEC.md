# 打碟谱规范 v3

**你写谱，DJ Studio 照谱打碟。** 这份规范说明打碟谱怎么写：曲目、每段过渡逐小节的旋钮位（EQ / Filter / 推子 / 效果器）、Hot Cue（Denon Prime 4+ 的 8 个打击垫）。
旋钮一律用 Prime 4+ 面板上的说法（钟点位、推子 0–10），程序按第 7 节的表换算，结果是确定的，同一份谱每次打出来都一样。

- **模板**：[score_template.md](score_template.md)，一份能直接跑的完整例子（3 首、2 段过渡）。复制它，改成你自己的 set 最快。
  DJ Studio 首页也能下载（「自己写谱：打碟谱规范 · 下载模板」）。
- **文件**：纯文本 Markdown，扩展名 `.md`，UTF-8 编码（VS Code、Typora、Obsidian 都行；用「文本编辑」要先切到「纯文本」）。文件名随意。
- **交给 DJ Studio**：把 .md 拖到首页（曲子可以一起拖进来）。最近拖进来的谱就是当前的谱。
  写错了，网页马上告诉你**第几行**哪里不对；改好再拖一次。
- 以前的《打碟谱》PDF 模板照样认；按 v1 / v2 写的 .md 谱也照样认（写法一样；自己写的 Hot Cue 必须写名字）。
- v2：Hot Cue 的打击垫不再有固定用途，改成按这一套 set 放每首的进、出和中间要处理的点（第 5 节）。
- v3：谱上写的 IN / OUT / STOP / FADE 说了算——打碟严格从这些位置进出，过渡里写的对不上直接报错（5.3）。

---

## 1. 整体结构

```
# 标题（set 的名字）

- 规范：v3                                ← 开头设置（第 3 节），都可以不写
- 开场：从第 1 小节起播
- 结尾：从第 177 小节淡出，淡出 16 小节

## 曲目                                    ← 曲目表（第 4 节）
| # | 曲名 | 文件名 | 原 BPM | 播放 BPM | Key Lock | 小节数 | 第 1 小节（秒） | 调性 |

## Hot Cue                                 ← 你另外想加的 hot cue（第 5 节），可以不写
### #1 曲名
| 垫 | 名字 | 颜色 | 位置 | 注释 |

## 过渡 1：第 1 首 → 第 2 首                ← 每段过渡：几条设置 + 旋钮表（第 6 节）
- 手法：长交接
- 进场：B 的第 1 小节落在 A 的第 129 小节
| A 小节 | B 小节 | A LOW | A MID | A HIGH | A Filter | A 推子 | B LOW | B MID | B HIGH | B Filter | B 推子 | 动作 |

## 过渡 2：第 2 首 → 第 3 首
…
```

- 段落标题（`## 曲目`、`## Hot Cue`、`## 过渡 N：…`）要照写；N 首歌就有 N − 1 段过渡，编号 1、2、3 … 连续。
- 表格的**列按表头的名字认**，顺序随意；表头里的空格、全角 / 半角括号不计较。可以不写的列整列删掉也行。
- 表格外面的文字、以 `>` 开头的行、`<!-- … -->` 都是写给自己看的，程序不读。别的 `## 段落`（比如 `## 思路`）也不读。

## 2. 小节怎么数（最重要）

- **每首歌数自己的小节**，4 拍 1 小节。过渡表里 A 小节 = 出曲的小节号，B 小节 = 进曲的小节号。
- **第 1 小节 = 你数小节的起点**：一般是曲子里最早的小节线（第一个 kick 的第 1 拍）。
  在 Engine DJ 里把播放头放到这一拍，把它离文件开头的时间写进曲目表的「第 1 小节（秒）」，DJ Studio 就按你的数法数。
  不写 = 用 DJ Studio 波形上的第 1 小节（曲库页能看到、能改小节线）。
- 「第 1 小节（秒）」会吸附到最近的一拍上。偏了超过 1/5 拍，或者你写的 BREAK / DROP 和程序切出的段落整体差几小节，网页会提示「可能对到了别的拍」。
- **小节.拍**（只有 hot cue 的位置用）：`33.1` = 第 33 小节第 1 拍，`33.3` = 第 3 拍；拍只能是 1–4。只写 `33` = 第 1 拍。
- 旋钮表里每一行写的是**那一小节第 1 拍时**旋钮的位置。

## 3. 开头设置

写在标题下面、第一个 `##` 之前，一行一条，都可以不写：

| 项 | 写法 | 不写时 |
|---|---|---|
| 规范 | `- 规范：v3` | v3 |
| 开场 | `- 开场：从第 17 小节起播`（第 1 首从哪一小节开始放） | #1 写了 hot cue IN 就从 IN；都没写 = 第 1 小节 |
| 结尾 | `- 结尾：播完`，或 `- 结尾：从第 177 小节淡出，淡出 16 小节`（最后一首的小节号）；最后一首写了 hot cue FADE 时只写 `- 结尾：淡出 16 小节` | 播完 |

## 4. 曲目表

`## 曲目` 下面一张表，一首一行，按上场顺序：

| 列 | 必填 | 写法 | 例子 |
|---|---|---|---|
| # | 是 | 上场顺序 1、2、3 … | `1` |
| 曲名 | 是 | 「曲名 — 艺人」（艺人可以不写） | `Satori — Charlotte de Witte` |
| 文件名 | 建议写 | 音频文件名。DJ Studio 按它在曲库里认歌；曲库里没有的，按它去「下载 / 桌面 / 文稿 / 音乐」里找 | `Charlotte de Witte - Satori.mp3` |
| 原 BPM | 是 | 曲子本身的 BPM | `132` |
| 播放 BPM | 否 | 这首独奏时的主控 BPM（不写 = 原 BPM）。偏离原 BPM 超过 6% 会提示，超过 16% 报错 | `134` |
| Key Lock | 否 | `开` / `关`（不写 = 关） | `关` |
| 小节数 | 否 | 从第 1 小节数到曲末一共几小节。用来核对找到的文件对不对（时长差 12 小节以上不认） | `160` |
| 第 1 小节（秒） | 建议写 | 见第 2 节；写 `0.250`、`0.250s` 或 `0:00.250` | `0.250` |
| 调性 | 否 | 随意（Camelot、Open Key 都行），只给自己看 | `8A` |

## 5. Hot Cue（Denon Prime 4+ 格式）

Prime 4+ 每首歌有 **8 个 hot cue**（HOT CUE 模式的打击垫 1–8：上排 1–4，下排 5–8），在 Engine DJ 里可以起名字、设颜色；另外有一个 **主 Cue**（CUE 键）。

### 5.1 原则：hot cue 跟着 set 走

**打击垫没有固定用途。** 一套 set 只关心每首歌什么时候进、什么时候出，以及中间要处理的点和变化——这些每首都不一样。
所以 DJ Studio 给每首放的，就是它在**这一套 set** 里要用到的点，**按时间先后从 1 号垫往后排**：

> IN（进）→ 进来时要处理的点 → OUT（出）→ 出去时要处理的点 → STOP（停）/ FADE（最后一首淡出）

上排 1–4 最常用，放的就是最先用到的这几个；多的接着放下排。这些点**从你的旋钮表里自动找**，不用另外写：

| 点 | 从谱上哪里来 |
|---|---|
| IN | 开场曲：「开场」的小节；其它：过渡里「进场」B 的那一小节。主 Cue 也放这里 |
| 进来时要处理的点 | 这首当 B 的那段过渡里，B 的旋钮 / 推子 / 效果在起播之后开始动的地方 |
| OUT | 这首当 A 的那段过渡，旋钮表的第一行 |
| 出去时要处理的点 | 那段过渡里 A 的旋钮 / 推子 / 效果开始动的地方 |
| STOP | 最后一行写了「停」的那一小节 |
| FADE | 最后一首：「结尾」里开始淡出的小节 |

「开始动」= 两行之间开始匀速拧的那一行，或者一下拧到位的那一拍；同一拍开始的几个动作算一个点。
动作分给动的那一首：A 的旋钮动了放在 A 上，B 的放在 B 上；换低频这种两边同一拍都动的，两首各一个点（A 上叫 BASS OUT，B 上叫 BASS IN）。
**旋钮表「动作」列写的字，会写进那一刻的 hot cue 注释**——所以动作写在开始动手的那一行。

名字（显示在 Prime 4+ 屏幕上）和颜色：

| 名字 | 颜色 | 什么时候放 |
|---|---|---|
| IN | 绿 #22D45A | 进：这首从这里起播（开场曲 = 起播小节；其它 = 过渡里进场的小节）。主 Cue 也在这里 |
| BASS IN / BASS OUT / MID UP / HIGH DOWN / EQ DOWN / HPF / LPF / FILTER OFF / FADER UP / FADER DOWN | 黄 #FFD60A | 过渡里这首的旋钮 / 推子开始拧，或一下拧到位 |
| ECHO / REVERB / ECHO OFF / REVERB OFF | 青 #00C8FF | 过渡里开 / 关效果 |
| LOOP 8 … | 粉 #FF5FA2 | 过渡里打 loop |
| OUT | 红 #FF3B3B | 出：这首当出曲的那段过渡从这里开始 |
| STOP | 紫 #A45CFF | 这首在这里停（谱上的「停」） |
| FADE | 红 #FF3B3B | 最后一首：从这里开始淡出 |

几个动作同一拍开始时名字连起来写（`REVERB LPF`），放不下 16 个字符时按 效果 > 低频 > Filter > EQ > 推子 留前面的；
注释里写全：第几段过渡、谱上的动作、每个旋钮从几点拧到几点、几小节拧到。

### 5.2 自己写 hot cue（可以不写）

想另外标的点（drop、人声、breakdown、自己的提示……）写在 `## Hot Cue` 里：每首一个小标题 `### #编号 曲名`（编号和曲目表一致），下面一张表：

| 列 | 必填 | 写法 |
|---|---|---|
| 垫 | 是 | 1–8，一首里不能重复 |
| 名字 | 是 | 显示在 Prime 4+ 屏幕上：**只用英文 / 数字，最多 16 个字符**（比如 `DROP`、`VOCAL`、`BREAK`）。中文写在注释里 |
| 颜色 | 否 | 下表的颜色名，或 `#RRGGBB`。不写按名字猜（IN 绿、OUT 红、DROP 橙、BREAK 蓝……，其它白） |
| 位置 | 是 | 谱上的「小节.拍」（`65.1`），或离文件开头的时间「分:秒.毫秒」（`1:58.404`，会吸附到最近的一拍） |
| 注释 | 否 | 中文，写这个点干什么用 |

可用的颜色名（在 Engine DJ 里选最接近的那个）：

| 颜色 | 色值 |
|---|---|
| 白 | #FFFFFF |
| 绿 | #22D45A |
| 蓝 | #2F7BFF |
| 橙 | #FF8C1A |
| 红 | #FF3B3B |
| 紫 | #A45CFF |
| 黄 | #FFD60A |
| 青 | #00C8FF |
| 粉 | #FF5FA2 |

- **你写的垫子一律不动**；自动找的点按时间先后放进**空着的**垫子（从小号起）。想让自动的点占上排，就把自己的点写在 5–8。
- 你写了和自动的点同名、位置差不到 1 小节的，自动的那个就不放了。你写了叫 `IN` 的垫子，自动的 IN 就让给它，主 Cue 也跟着它。
- 点比空垫子多时：先留 IN / OUT / STOP / FADE，再留效果，其它按时间先后。
- 名字叫 BREAK / DROP 的点同时也是段落标记：小节对齐时拿来和程序切出的段落核对。
- 结果在网页首页「Hot Cue 表（Prime 4+）」里（可以下载）：每个垫子写三种位置——DJ Studio 的小节.拍、谱上的小节.拍、离文件开头的时间，照着在 Engine DJ 里设一遍。

### 5.3 IN / OUT / STOP / FADE：hot cue 说了算

谱上写了这几个名字的垫子，打碟就**严格从这些位置进出**；过渡里写的和它们对不上，拖进来就报错（带行号），不替你挑一个：

| 名字 | 管什么 | 过渡 / 开头设置里要怎么写 |
|---|---|---|
| IN（或 MIX IN） | 这首从这里起播（第 1 首 = 开场） | 进场可以只写 `B 的 IN 落在 A 的第 X 小节`；写了「B 的第 N 小节」就必须和 IN 一样。第 1 首不写「开场」就从 IN 开始 |
| OUT（或 MIX OUT） | 这首当出曲的那段过渡从这里开始 | 那段过渡的旋钮表，第一行必须是 OUT 那一小节 |
| STOP | 这首在这里停 | 那段过渡的最后一行必须写 `X 停`，X = STOP 那一小节 |
| FADE | 最后一首从这里开始淡出 | 开头写 `- 结尾：淡出 M 小节`（写了「从第几小节」就必须和 FADE 一样） |

- IN / OUT / STOP 要在小节的第 1 拍上（写 `小节.1`）：进出是两首的第 1 拍对第 1 拍。
- 用时间写（`分:秒.毫秒`）也行：过渡 / 开头设置里照样写小节，曲子分析完后程序把时间换成这首的拍来核对——
  不是同一拍就报错，告诉你这个时间是谱上第几小节第几拍；是同一拍但差 25 毫秒以上会提示（Engine DJ 的网格和这里差一点），照拍放。
- 一首里同一个名字只能写一个。
- 这几个点和别的自动点一样出现在 Hot Cue 表里（照你写的垫号、颜色、注释）。

## 6. 过渡

每段过渡一个段落：`## 过渡 N：A 的曲名 → B 的曲名`（过渡 N = 第 N 首交给第 N+1 首；A = 出曲，B = 进曲）。

### 6.1 设置（每段几条 `- 项：值`）

| 项 | 必填 | 写法 | 说明 |
|---|---|---|---|
| 手法 | 是 | `长交接` / `瞬时切换` | 只是标签（演出页上显示），怎么交接全看旋钮表 |
| 进场 | 是 | `B 的第 1 小节落在 A 的第 129 小节`；B 写了 hot cue IN 时可以写 `B 的 IN 落在 A 的第 129 小节` | B 从自己的第几小节开始放、对在 A 的第几小节上（两边都是第 1 拍）。drop 对 drop：`B 的第 33 小节落在 A 的第 97 小节` |
| 主速 | 两首播放 BPM 不同时必填 | `132`，或 `130 → 132，B 第 17–24 小节换` | 主控 BPM。换速写 B 的小节：从第 17 小节第 1 拍开始，到第 24 小节结束时换完（匀速）。只写一个小节 = 在那一小节里换完 |
| 效果 | 否，可以写多条 | `A Reverb，第 153–160 小节，湿度 1/3` | 见 7.4。小节是这个 deck 自己的小节号；湿度写 `1/3`、`0.5`、`50%` 都行 |
| 说明 | 否 | 随意 | 给自己看 |

### 6.2 旋钮表

| A 小节 | B 小节 | A LOW | A MID | A HIGH | A Filter | A 推子 | B LOW | B MID | B HIGH | B Filter | B 推子 | 动作 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 121 | — | 12点 | 12点 | 12点 | 关 | 10 | — | — | — | — | — | 过渡开始 |
| 129 | 1 | 12点 | 12点 | 12点 | 关 | 10 | 7点 | 12点 | 11点 | 关 | 5 | B 起播：半推子，LOW 切掉 |
| 144 | 16 | | | 11点 | | | | | 12点 | | 10 | |
| 145 | 17 | 7点 | | | | | 12点 | | | | | 换低频：同一拍 |
| 160 结束 | 32 | 7点 | 9点 | 8点 | 左9点 | 10 | | | | | | A 播完 |

**必须有的列**：A 小节、B 推子。其它可以不写（整列不写 = 一直不动：EQ 12 点、Filter 关、A 推子 10）。B 小节只用来核对，可以不写。

规则：

1. **一行 = 那一小节第 1 拍时旋钮的位置。** 两行之间匀速拧过去（直线变化）。
2. **一下拧到位**：在前一小节写一行原来的位置，下一小节写新位置——相邻两行只差 1 小节、而且变化 ≥ 2 个钟头（EQ / Filter）或 ≥ 3 格（推子），就在后一行那一拍直接跳过去（上表 144 → 145 的换低频）。差得小的照样在这 1 小节里匀速拧。
3. **空格 = 和上一行一样。** A 的第一行空着 = 12 点 / 关 / 推子 10。
4. **第一行 = 过渡开始**（A 的 MIX OUT），时间线从这里开始；它不能晚于 B 进场。
5. **B 进场之前**，B 的格子写 `—` 或空着。**B 进场那一小节**（6.1「进场」里 A 的那个小节）**必须有一行**，而且要写 B 推子；B 的 EQ / Filter 空着 = 12 点 / 关。
   B 进场那一行的旋钮位在 B 起播前就已经摆好（像真机上先把 B 的 LOW 拧掉再推推子）。
6. A 小节一行比一行大。B 小节写了就要和「进场」对得上：B 小节 = A 小节 − A 的进场小节 + B 的进场小节。
7. **最后一行**的 A 小节后面写：
   - `结束`：A 自己播到曲尾（出曲推子不拉，交给 EQ 和 A 自己的结尾）。写 A 的最后一小节；和文件实际的长度差 2 小节以上会提示。
   - `停`：A 在这一小节的**第 1 拍**停（drop 对 drop、硬切）。这一行 A 的格子可以空着。
8. 最后一行之后 B 的旋钮保持最后一行的位置，B 接着独奏，直到下一段过渡的第一行。
9. **动作**列写在开始动手的那一行：这些字会写进那一刻的 hot cue 注释（第 5 节）。

## 7. 旋钮位怎么写（Prime 4+）

### 7.1 EQ（LOW / MID / HIGH）

写**钟点位**：`12点` = 平，往左拧到 `7点` = 切到底，往右到 `5点` = 最大。半点写 `11点半`。`7点(切)` 也认。
颜色（DJ Studio 的旋钮、曲线、波形里）：LOW 蓝、MID 绿、HIGH 白。

| 钟点位 | dB |
|---|---|
| 12 点 | 0 |
| 11 点半 | -0.7 |
| 11 点 | -2.0 |
| 10 点半 | -3.8 |
| 10 点 | -6.0 |
| 9 点半 | -8.5 |
| 9 点 | -11.3 |
| 8 点半 | -14.3 |
| 8 点 | -17.7 |
| 7 点半 | -21.2 |
| 7 点 | -25.0 |
| 1 点 | 1.2 |
| 2 点 | 2.4 |
| 3 点 | 3.6 |
| 4 点 | 4.8 |
| 5 点 | 6.0 |

- 7 点按「切到底」算（混音里听不到这个频段）。10 点 ≈ -6 dB =「给到一半」。
- 参考（职业 DJ 实测）：长交接一般不把低频完全杀掉，低频凹 0.4–6.5 dB 就够；A 的 HIGH 从 B 的 kick 进来起每小节缓降一点（≈ 0.2 dB）。

### 7.2 Filter（每个通道一个旋钮）

| 写法 | 意思 |
|---|---|
| `关`（或 `12点`） | 不滤 |
| `左11点` … `左7点` | 低通（LPF，往左拧，声音越来越闷）；`左7点` = 拧到底 |
| `右1点` … `右5点` | 高通（HPF，往右拧，声音越来越薄）；`右5点` = 拧到底 |

半点写 `左10点半`。`左9点` / `右3点` = 拧了一半。不写左右时按位置认（`9点` = 左 9 点，`3点` = 右 3 点）。

### 7.3 推子（0–10）

写 `0` … `10`（可以写小数，比如 `7.5`）。和 Mixxx / 真机推子同一条曲线，推子 5 不是一半音量，是 -12 dB 左右：

| 推子 | 实际增益 dB |
|---|---|
| 0 | -∞ |
| 1 | -30.8 |
| 2 | -23.7 |
| 3 | -19.1 |
| 4 | -15.5 |
| 5 | -12.4 |
| 6 | -9.6 |
| 7 | -7.0 |
| 8 | -4.6 |
| 9 | -2.3 |
| 10 | 0.0 |

- 常见做法：B 先半推子（5）进，过一段再推满（两级）；出曲（A）的推子不拉。
- 不用 crossfader（居中，两边都是满音量），混音只用通道推子。

### 7.4 效果器（Main FX）

两个效果，A、B 共用（同一时间两边开同一个效果会提示）：

| 效果 | 固定参数 |
|---|---|
| Echo | 延迟 1/2 拍（跟拍）、反馈 -3 dB、送出 -3 dB |
| Reverb | 衰减 0.5、带宽 1、阻尼 0、送出满 |

- 湿度 = Wet/Dry（0 = 只有原声，1 = 只有效果声）。`1/3` 是常用的「混进去一点」。
- 「第 a–b 小节」= 第 a 小节第 1 拍打开，第 b 小节结束时关掉。
- **A 的效果开到 A 结束 / 停的那一小节**：不关，让混响 / 回声的尾巴自己响完（A 停了尾巴还在，几秒后自动归位）。
- 效果在推子后面：A 推子拉到底，尾巴还在。

## 8. 速度、Key Lock、音量

- **速度**：每首独奏时按曲目表的「播放 BPM」；过渡里按「主速」，换速写在 B 的哪几小节。两首始终同步（拍对拍）。
- **Key Lock**：现在一律按「关」放（变速时音高跟着变一点），写了「开」也先按关放：Mixxx 的时间拉伸会让变速的那首晚 17–29 毫秒，两个 kick 叠在一起会出「双击」。
- **音量**：不用写。每首自动统一到 -14 LUFS（像 Prime 的 Auto Gain），往上提时峰值不超过 -1 dBFS。

## 9. 写完检查一遍

- [ ] 标题一行 `# …`；`## 曲目` 表里每首有 #、曲名、原 BPM，最好有文件名和第 1 小节（秒）
- [ ] N 首就有 N − 1 段 `## 过渡 N：…`，编号连续
- [ ] 每段有「手法」「进场」；两首播放 BPM 不同时有「主速 … B 第 m–n 小节换」
- [ ] 写了 IN / OUT / STOP / FADE 的：进场、旋钮表第一行、最后一行的「停」、结尾都和它们一样（5.3）
- [ ] 旋钮表：B 进场那一小节有一行、写了 B 推子；最后一行写了「结束」或「停」
- [ ] 下一段过渡的第一行（B 的出点）在这一段结束之后
- [ ] 动作写在开始动手的那一行（会变成 hot cue 的注释）
- [ ] 自己加的 Hot Cue：名字只用英文，≤ 16 个字符；位置的拍只能是 1–4

拖进首页后，网页会显示读出来的曲目和过渡、哪首对上了曲库里的哪个文件，以及提示 / 错误（带行号）。

## 10. 还不能写的

- 拍级的动作（旋钮表最小单位 1 小节；比如「最后一拍真空」写不了）
- Loop、Beat Jump、Sampler
- 三首同时叠在一起（同一时间最多两首）
- A 停了以后 B 的旋钮再变（最后一行之后 B 保持不动）
