# DJ Studio 更新记录

每一版改了什么（新的在前）。每一版在 GitHub 上都有对应的提交：点版本后面的提交号，就是那一版的全部代码；提交说明里有更细的技术细节和测试结果。
从 0.3.19 起，每一版还会在 GitHub 的 Release 页单独留一个 `v版本号` 的发布（带这一版的说明和应用下载），旧版本也能下回来；
`mac-app-latest` 一直是最新版（README 里的安装命令从这里下）。

## 0.4.5 — 2026-11-24

**调音台放回 EQ 曲线旁边了**（四 Deck 的演出画面）：上一版把调音台挪到了最下面一排，旋钮和它们的线隔得太远。

- 现在**左边是调音台**（EQ / Filter 旋钮、推子、电平），**右边是 EQ / Filter / 推子的曲线**，并排——看着线，手边就是那个旋钮。
  调音台底下是「现在的 EQ 操作」（正在拧哪个、拧到哪、还剩几小节）。最下面一排剩两块：「接下来」和这个场景的「策略」。
- 上一版改好的都留着：页面用满窗口的宽度；曲线一页一页地翻（默认一页 = 一个场景），页不动、游标走；放的时候各块不挪位置。
  左边这一列是定宽的（跟着有几台 Deck 走），里面的字多字少，曲线不会跟着变窄变宽。
- 曲线比整行宽的时候窄了一些，所以一小节最窄可以画到 12 像素：48 小节、64 小节的场景在 13 寸屏上还是一页放得下。
- 标尺上「132→134 BPM」这种变速的字不再和小节号叠在一起。

**要知道的**：和上一版一样，只在 Linux 的测试浏览器里看过（1180、1440、1920 三种宽度），Mac 上没看过。

## 0.4.4 — 2026-11-24

四 Deck 的演出画面重排了一遍：上面是整首曲子和整套 set 的安排，画面用满窗口的宽度，放的时候不再跳，每一块只写自己的事。

从上到下现在是：**头**（位置、Set 时间、主速、场景 + 整套 set 的安排 + 主要的交接）→ **整首曲子**（每台 Deck 一行）→ **滚动波形**（每台 Deck 一行）
→ **EQ / Filter / 推子的曲线**（整行宽）→ 最下面一排 **调音台｜现在的 EQ 操作｜接下来｜策略**。

- **上面是整首曲子了**（和两 Deck 时一样；以前上面那块和下面的滚动波形画的是同一样东西）：每台 Deck 一行，画它现在放的——没在放就画下一段要放的——那首原曲的**整首波形**。
  - **选用的那一段框出来**（Deck 的颜色），写着「选用 第几–第几 小节」、几个乐句；起播、停、Loop（几小节 × 几圈）、跳段都标着原曲的小节号；
    这套谱不放的部分压暗。
  - **Hot cue 标在波形上**：带打击垫号的小旗（颜色 = 种类）。下面的滚动波形上也有，带名字（`1 IN`、`5 MID UP`……）。
  - **点波形就是选播放位置**：问一句「从原曲第几小节（全场第几小节）重新开始」；这套谱不放的那一段点不了。
  - 每行左边写着**要这首的哪些元素**：LOW / MID / HIGH 三个色块——亮着 = 要，划掉 = 从头到尾切着，「后进 / 后切」= 中途放进来 / 切掉；后面是谱上这个片段的备注。
- **整套 set 的安排**：最上面多了一张小图——场景一行，主要的交接一行，每台 Deck 一行，色块是片段（浅一点的是 Loop，底下的黄条是效果），游标走到哪一目了然。
  点场景 = 从那个场景的开头放，点色块 = 从那一小节放。原来的场景条并进了这张图。
- **分清主线和工具**：轨道多了，不是每一条都是「一首歌」。角色是 主曲 / 进曲 / 出曲 的片段是**主线**，别的（节奏层、声线…）是**工具**——
  安排图里主线是粗的色块、工具是细的；整首曲子那一行写着「主线」或「工具」，工具的框是虚线。
  主线上一首接一首的地方是**主要的交接**：安排图和曲线上橙色的一段，换低频的那一拍一条蓝线；头上有一行「交接 1 进行中：谁 → 谁 · 哪一拍换低频（还有几小节）· 还有几小节交完」，
  没在交接时写下一次在哪。出曲的 hot cue 里多了 OUT（交接开始的地方）。谱上没写角色的片段按样子分（[曲谱规范 v5](SCORE_SPEC_V5.md) 第 13 节）。
- **画面不跳了**：
  - **EQ 曲线一页一页地看**，不再跟着播放一直往左滑：这一页的线不动，游标从左走到右。默认一页 = 一个场景，换场景才翻；
    也可以选一页 8 / 16 / 32 小节——游标走到最后四分之一页时翻，新的一页从游标那里开始，所以后面要做的动作一直看得到。拖动 / 横向滚动可以自己前后翻。
  - **每一块定高、定宽**：以前一个效果亮起来、读数从「12点」变成「7点(切)」、BPM 变成小数、出现「回谱」按钮或「过载 n 次」，
    调音台就会变宽变高，把旁边的东西挤着挪。现在这些位置都留好了，字变了别的不动；字多的列表（接下来、EQ 操作）在自己的框里滚。
  - **游标和滚动波形匀着走**：以前每收到一次引擎的状态（一秒四五次）就顿一下或者窜一下，现在按速度连续走、把差的慢慢补上。
- **每一块只写自己的事**，同一句话不再写两三遍：
  - 头上：现在在全场哪里、Set 放到几分几秒 / 一共多长 / 还剩多久、主速、哪个场景的第几小节；
  - 整首曲子：这首是主线还是工具、整首多长、选用哪一段、要它的哪些元素；
  - 滚动波形：现在读到原曲第几小节、第几拍、乐句、这一段还剩多久，以及这份素材自己的速度（原曲的 BPM、现在比原曲快 / 慢百分之几——
    主速四台都一样，只在头上写一次）；待命的 Deck 只写「几小节后进」；
  - 曲线：谱上每个旋钮怎么走（左边只留旋钮的名字，读数看调音台）；
  - 调音台：旋钮、推子、电平的实际值；「现在的 EQ 操作」只写正在拧的和保持着的；「接下来」是动作和回执；「策略」是这个场景的说明。
- **页面变宽了**：四 Deck 的演出页用满窗口的宽度（以前两边留着白），曲线和波形都宽了；调音台收窄到和两 Deck 时一样紧凑，放在曲线下面，不再挤曲线。
  旋钮下面那行 dB 的小字省掉了（钟点位照旧），调音台底下写着怎么手动接管。
- **Set 时间**：头上显示「放到几分几秒 / 一共多长」和还剩多久。
- **四 Deck 的谱也有 Hot Cue 表了**（「可以演出了」那一屏和演出页右上角）：每份素材的打击垫 1–8，照着在 Engine DJ / Prime 4+ 上设。
  规矩和两 Deck 的一样——打击垫没有固定用途，放的是这份素材在这套谱里要用到的点：IN、旋钮 / 推子开始拧的地方、效果开关、LOOP、JUMP、STOP，
  按在原曲上的先后从 1 号垫排（[曲谱规范 v5](SCORE_SPEC_V5.md) 第 12 节）。

**要知道的**：和上一版一样，这个画面只在 Linux 的测试浏览器里看过、点过（1180、1440、1920 三种宽度），Mac 上没看过；演示素材是合成的，波形几乎只有蓝色。
「不跳」是在测试浏览器里量的：放的时候逐个记页面上每个元素的位置，除了本来就在变的字，别的都没有挪。

## 0.4.3 — 2026-11-23

**四 Deck 的画面改回以前两 Deck 时的样子**，以前有的东西四 Deck 也有了。（旧谱 v1–v4 的画面没动。）

- **波形回来了**：每台 Deck 都是原曲的蓝 / 绿 / 白三频段波形（蓝 = 低频、绿 = 中频、白 = 高频，和 Prime 4+ 上一样）。
  上面是全场总览——每台 Deck 一行，片段摆在全场小节上，Loop 一圈一圈地重复，带子底下是原曲的小节号；
  下面是每台 Deck 自己的滚动波形，播放头在正中，写着原曲第几小节、第几拍、乐句、速度、还剩多久。点波形就问你「从全场第几小节放」。
- **调音台回来了**：四路 + 主输出，HIGH / MID / LOW / FILTER 旋钮、发送效果、推子、电平表，和两 Deck 时是同一套，显示的是引擎读回的实际值。
  **拖旋钮或推子就是手动接管它**（变成橙色，别的照常跟谱），通道下面出现「下一拍回谱 / 下一小节回谱」，双击也能回谱；键盘 ↑ ↓ 也能拧。
  原来那块单独的「手动接管」滑杆面板没有了。
- **EQ 线回来了**：每台 Deck 一组，HIGH（白）、MID（绿）、LOW（蓝）、FILTER、推子各一条线，左边的小旋钮是实际值，游标上的点是谱上这一拍该在哪；
  落在这台 Deck 上的效果画在它那一组的头上。调音台下面是大字的「现在的 EQ 操作」：谁的哪个旋钮正在拧、拧到几点、还剩几小节，下一个 EQ 动作在哪。
- **四 Deck 的谱也能「● 录成 MP3」**：「可以演出了」下面多了和旧谱一样的录音面板。不出声，在后台尽快放一遍
  （最快 20 倍速，实际多快看电脑——测试机上 7 分钟的示例谱不到 1 分钟），录出来和原速演出是同一份声音：从 1.1 录到全场结束，
  最后的效果尾音也在里面，320 kbps，存在「音乐 / DJ Studio 录音」。放得太快有片段来不及装、或者读盘没跟上，会自动放慢重录；录的时候不能开始演出。
- 场景按钮换成了一条按长短排开的场景条（点哪一格从哪个场景开始）；没在放的时候，旋钮和推子照谱上游标那一拍的位置摆着。
- 留着的：暂停 / 跳转、接下来的动作和回执、当前场景的策略、交接说明。

**要知道的**：这个画面只在 Linux 的测试浏览器里看过、点过，Mac 上（尤其是 Safari）还没看过；演示用的合成素材波形几乎只有蓝色，
真曲子的三层颜色要你放自己的曲子才看得到。录音在 Mac 上实际多快还没量过，第一次录完请从头听一遍。哪里不对告诉我。

## 0.4.0 — 2026-11-22

**四 Deck 和现场效果。** 以前的打碟谱（v1–v4）不用改，照旧能放；下面这些是新的一种谱（v5）带来的。

- **四台 Deck，一条全场小节轴**：主曲、打击乐循环、一句人声、下一首可以同时放在 D1–D4 上。谱里把「素材」和「片段」分开写，
  每个片段写放在哪台 Deck、从原曲哪里起、全场哪一拍起播 / 停；Loop 可以转任意多圈、越收越短，跳段只动那一个片段。
  四台的起播落在同一个采样上（Linux 上的声音引擎实测偏差 0.03 毫秒以内）。
- **任何时候都能动旋钮，独奏时也行**：参数表（LOW / MID / HIGH / Filter / 推子）写在哪一拍都可以，不再只限过渡里；
  「保持」「直接写值 = 匀速拧到」「跳 7点 = 一下到位」是写明的，程序不按变化大小猜。
  演出时可以**手动接管**任何一台 Deck 的任何一个旋钮（别的照常跟谱），再点「下一拍回谱」或「下一小节回谱」。
- **每个场景写「为什么」**：作用、保留什么、谁到前景、低频在哪一拍换、MID / HIGH 动不动。图上、提示里、交接说明里是同一份。
  两个低频 / 两条声线 / 几条中频主题叠在一起时给提示（不是报错），可以标成「有意」。
- **效果各有各的实例**：
  - DJ 常用的 Delay / Echo / Reverb 走发送，每个片段自己的一份，D1 的 Echo 关掉、换曲都不影响 D2 的；片段停了尾音照样响完。
  - 现场效果（走插入 / 组插入 / 总输出）：只切某个频段的 Trans、Roll（1 拍 → 1/2 → 1/4 越切越碎）、Filter、Filter Echo、Spiral、Noise、
    Flanger、Phaser、采样 fill（内置几种鼓，或自己的短音频）、Release（Echo / 刹车 / 回转，放完「回原声」或「退场」）。
- **演出画面换成四 Deck 共轴图**（v5 的谱）：四条播放带（带里是原曲的小节号）、每个旋钮一行、效果和 Loop 的带子、当前场景的策略、
  接下来 4 小节要做什么。每个动作做没做完只看引擎的回执（晚了 / 跳过 / 失效会标出来）。可以全场暂停、点标尺从任意一小节重新开始
  （从中间开始会先静音把效果的尾音、Roll 抓到的那一段补出来）。
- **交付就是一个文件夹**：谱（.md）和谱上写的原曲放在一起，整个文件夹拖进来；「导出演出包」生成这样一个文件夹（原曲原样拷贝、核对哈希，
  不生成混音）。「交接说明」是一页能打印 / 存成 PDF 的四 Deck 操作图，每个场景一张，长的场景分几条。
- **旧谱**：可以「另存为 v5 的谱」（原来的不动）；`djstudio v5check <set>` 把旧 set 按新编译器再编一遍，逐点核对是不是等价。
- 写谱：[曲谱规范 v5](SCORE_SPEC_V5.md)、[示例谱](score_v5_example.md)；没有自己的曲子可以 `djstudio demo5` 看示例。

**要知道的**：

- 这一版的四 Deck 引擎和现场效果只在 Linux 上的声音引擎里测过（时间、电平、不爆音），**还没有人在 Mac 上听过**；
  效果的音色好不好听要你在 app 里听了才知道（哪种不对告诉我）。Mac 上的构建会自动跑一遍四 Deck 的冒烟测试。
  满负载（四路 MP3 + 8 个发送效果 + 4 个处理组）在测试机上平均只用了每个音频块预算的 13%，连放一小时不崩、不漂；
  但那台机器测不出「会不会掉音」，这一条要在 Mac 上跑过才算数（怎么跑见 [V5_G0.md](V5_G0.md)）。
- v5 的谱只在内置引擎里放；连本机 Mixxx 的模式只能放 v1–v4。
- 还没做：演出中临时按按钮加一个效果（现在效果都写在谱里）、单独暂停某一台 Deck、v5 的 Hot Cue 表、
  Key Lock 的延迟补偿（默认关，开了会提示）、48 kHz / 256 帧的引擎配置。v5 的谱没有「录成 MP3」（交付的是谱和原曲，不生成混音）。
  量出来的数字和没做的细节见 [V5_G0.md](V5_G0.md)。

## 0.3.26 — 2026-11-05

- **找曲子不再被别的 set 的 U 盘目录带偏**：文件名前的编号（= 谱上的曲序）只在名字本来就对得上时加一点分（同一首有几份时挑编号对的那份）。
  以前编号加分太多，同一个艺人的歌名字前半截一样，别的 set 的「08 … Overdrive」会压过谱上 #08 的「Kali」原文件
  （60 分钟 set v1 录音里 5 首放错）。对到的文件名字不太像（< 0.9）时，生成 set 的日志里提示一条。
- **同一小节写两个跳段 / loop 报错**：引擎会在同一拍一起做，「先跳回去、第二遍再往后跳」往回跳那一下等于没做
  （60 分钟 set v1 少放了 248 小节）。改写成「loop N 小节 × 2」再在 loop 结束的那一小节跳。
- **独奏 loop 之后紧接着的动作不再提前做**：loop 尾那一小节写的跳段、或者正好在 loop 尾开始的过渡，以前会在 loop 第一遍转到尾巴时就做
  （Mixxx 跳回 loop 头那一刻，位置读数还没跟上，拍号多算了一点点）。现在 loop 转完才做。
- **Prime 4+ 打击垫**：loop 头和跳段落点一样优先（以前 8 个垫子放满时 loop 头最先被挤掉）；换低频那一拍排在别的旋钮点前面；
  OUT 和跳段落点在同一个位置只占一个垫子。

  （Overdrive、Sanctum、Stigma、Fourth Dimension、High Street、Pria 这类前奏是 kick + 反拍 bass 的曲子，网格线离 kick 差将近半拍，
  同步时这首的 kick 会落在另一台的反拍上）。
  - 谱上写的「第 1 小节（秒）」为准：网格的拍离它 0.2 拍以上，就按谱把网格整体挪过去（BPM 不变），这首以后就用这条网格（曲库页标「按谱」），
    日志里写「N 首的网格离谱的第 1 小节差 0.2 拍以上，按谱把网格挪到第 1 小节上」和每首挪了多少毫秒。再跑一次就不用再挪。
  - DJ Studio 自己估网格时也会看半拍外：kick 的音高在起音后往下扫，bass 不扫，半拍外明显更像 kick 就换过去。升级后会按新办法重新估一遍网格。
  - 第 1 小节在文件开头前一点点（50 毫秒以内）也能从那里起播，不再报错（Mixxx 会先放这一点静音）。
  - 连 Mixxx 时：挪过的网格写进 Mixxx 并锁定（先备份），「网格核对」不再拿自估网格把它改回去。

## 0.3.22 — 2026-11-01（提交 [0e04d79](https://github.com/bg1eym/dj-studio/tree/0e04d79)）

- 修了**EQ 旋钮和声音对不上**（你听到的「MID 旋钮下去了声音没变，到乐句末尾突然变了」）：内置声音引擎的 EQ 分频点一直设错了（11 kHz，应该是 250 Hz / 2500 Hz）——
  - MID、HIGH 只动 11 kHz 附近，旋钮转了几乎听不出来；
  - LOW 却把 11 kHz 以下全切掉，一拧 LOW 整首都下去，听起来像「突然变了」。
  - 这是 0.3.0 做内置引擎时就有的问题，和这两天改网格无关。真 Mixxx 启动时由偏好设置把分频点设成 250 / 2500 Hz，内置引擎没有偏好设置，漏了这一步。
- 现在三个旋钮各管各的频段（实测：LOW 拧到底只切低频、MID 只切中频、HIGH 只切高频，别的频段动不到 1–2.4 dB），过渡里 MID 慢慢拧下去，声音一拍一拍跟着变。
- 分频点对了以后，Mixxx 的 EQ 本身会让声音晚 1.3 毫秒（真 Mixxx 一样，两个 deck 一样晚，对拍不受影响）；演出页的播放头把它算进去了。
- 加了测试：在真引擎里放粉噪逐个旋钮量频段；打一段 MID 渐变的 set，录音里的中频和旋钮逐拍比对。
