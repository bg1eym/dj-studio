每一版改了什么（新的在前）。每一版在 GitHub 上都有对应的提交：点版本后面的提交号，就是那一版的全部代码；提交说明里有更细的技术细节和测试结果。
从 0.3.19 起，每一版还会在 GitHub 的 Release 页单独留一个 `v版本号` 的发布（带这一版的说明和应用下载），旧版本也能下回来；
`mac-app-latest` 一直是最新版（README 里的安装命令从这里下）。

## 0.3.23 — 2026-11-02

- **● 录成 MP3**：首页「可以演出了」下面点一下，整套 set 录成一个 MP3（320 kbps），存在「音乐 / DJ Studio 录音」，网页上能直接下载、在访达里显示。
  - 快：不出声、20 倍速在后台放一遍，90 分钟的 set 大约 4–5 分钟录好，有进度条，可以取消。
  - 和演出一模一样：同一个 Mixxx 引擎、同一份谱、旋钮推子效果、每首统一的音量都一样；倍速时旋钮也是按音乐的时间拧的（不是按电脑的时间），录出来和原速放的逐点相同。
  - 开头结尾的静音去掉；文件标题是 set 名（中文不乱码）。
  - 电脑太忙读盘跟不上（录音里会有缺口）时会发现，自动放慢重录。
  - 录的时候不能开始演出。
- 打碟脚本 DJStudio.js 0.4.4（录音时按引擎的时间走）。

## 0.3.22 — 2026-11-01（提交 [0e04d79](https://github.com/bg1eym/dj-studio/tree/0e04d79)）

- 修了**EQ 旋钮和声音对不上**（你听到的「MID 旋钮下去了声音没变，到乐句末尾突然变了」）：内置声音引擎的 EQ 分频点一直设错了（11 kHz，应该是 250 Hz / 2500 Hz）——
  - MID、HIGH 只动 11 kHz 附近，旋钮转了几乎听不出来；
  - LOW 却把 11 kHz 以下全切掉，一拧 LOW 整首都下去，听起来像「突然变了」。
  - 这是 0.3.0 做内置引擎时就有的问题，和这两天改网格无关。真 Mixxx 启动时由偏好设置把分频点设成 250 / 2500 Hz，内置引擎没有偏好设置，漏了这一步。
- 现在三个旋钮各管各的频段（实测：LOW 拧到底只切低频、MID 只切中频、HIGH 只切高频，别的频段动不到 1–2.4 dB），过渡里 MID 慢慢拧下去，声音一拍一拍跟着变。
- 分频点对了以后，Mixxx 的 EQ 本身会让声音晚 1.3 毫秒（真 Mixxx 一样，两个 deck 一样晚，对拍不受影响）；演出页的播放头把它算进去了。
- 加了测试：在真引擎里放粉噪逐个旋钮量频段；打一段 MID 渐变的 set，录音里的中频和旋钮逐拍比对。

## 0.3.21 — 2026-11-01（提交 [eb6022b](https://github.com/bg1eym/dj-studio/tree/eb6022b)）

- **网格按谱定**：谱上写的原 BPM 和自动估的不一样时，不再报错停下，而是按谱上的 BPM 把整首的 kick 对一遍（30 秒一段，看 kick 是不是都落在拍线上）：
  - 对得上（自动估错了，比如 How You Move 138 估成 137）→ 网格按谱，以后重新分析也按它；曲库页标「按谱」。
  - 对不上（谱上的 BPM 写错了）→ 按音频的 BPM 打，谱上的小节和主速照旧，set 照样生成，只提示「按 13x 对 kick，几段里只有几段对得上」。
  - 两首谱上的 BPM 正好对调了（比如 Soma / Satori 的 138 和 136），会提示可能写反了。
- 曲库页点一首能看到按谱对 kick 的结果；曲库页手动定的网格程序不动。

## 0.3.20 — 2026-11-01（提交 [af15592](https://github.com/bg1eym/dj-studio/tree/af15592)）

- 修了**BPM 估错**（#09 How You Move 谱上 138，网格估成 137.00）：以前先粗估一个速度，再只在它前后 1% 里细找；粗估偏了 1% 以上，就只能停在那个范围的边上（137.00 正好是边）。现在先在 ±4% 里用整首最有 kick 的几段一起找，再在整首上细找，粗估偏 3–4% 也能找回 138.000。
- 以前分析过的曲子，下次分析时会按新办法**重新估网格**（不用你手动删）。
- **手动定网格**：曲库页点一首 →「网格」里填 BPM 和第一拍（秒）→「按这个网格」，小节、段落、打碟谱转换都按你填的走；「用回自动估的」撤销。万一程序还是估错，用这个兜底。
- 谱上 BPM 和网格对不上时，错误提示直接告诉你去哪里改网格。

## 0.3.10 — 2026-10-31（提交 [6c5b388](https://github.com/bg1eym/dj-studio/tree/6c5b388)）

- **Hot Cue 跟着 set 走**（播放规范 v2）：打击垫没有固定用途。每首放的是它在这一套 set 里的点：IN（进）→ 进来时要处理的点 → OUT（出）→ 出去时要处理的点 → STOP / FADE，按时间从 1 号垫排（上排 1–4 最常用）。
- 处理点从过渡里找：旋钮 / 推子开始拧、一下拧到位、开关效果。名字按动作取（BASS IN、HIGH DOWN、REVERB LPF…），颜色表示种类（绿进、红出、黄旋钮、青效果、紫停）；注释写谱上的「动作」和旋钮从几点拧到几点。
- 谱上自己写的垫子不动，自动的只放进空着的垫子。
