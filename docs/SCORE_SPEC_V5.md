# 曲谱规范 v5（四 Deck）

> 版本：v5 · 对应的解析器：`djstudio/v5/score.py`（`SCORE_VERSION = "5"`）· 示例：[score_v5_example.md](score_v5_example.md)
>
> v1–v4 的打碟谱（[SCORE_SPEC.md](SCORE_SPEC.md)）照旧能用，不用改。v5 是给「同时用到两台以上的 Deck」的编排写的：
> 素材和片段分开、所有东西写在同一条全场小节轴上、旋钮在任何时候都能动（包括独奏）、效果有自己的路由。

一份 v5 的谱是一个 Markdown 文件，开头写着 `- 规范：v5`。把它和谱上写的原曲 **放在同一个文件夹里**，整个文件夹拖进 DJ Studio。
以 `>` 开头的行是写给自己看的，程序不读。表格的列可以少写（不用的旋钮不用列出来），列的先后随意。

DJ Studio 0.4.6 起可以多写一张「元素」表（第 14 节）：每份素材的 kick、bass、镲、人声……在原曲的哪几小节有。不写也能演出，以前的谱不用改。

## 0 位置和时长怎么写

| 写法 | 意思 |
|---|---|
| `33.1` | 第 33 小节第 1 拍（小节和拍都从 1 数；一小节 4 拍） |
| `32.4+1/2` | 第 32 小节第 4 拍再过半拍 |
| `8拍`、`2小节`、`1/2拍`、`3/4拍` | 时长。单位必须写（`拍` 或 `小节`） |

**全场位置**（场景、起播、停止、旋钮、效果的位置）是全场小节轴上的；**原曲位置**（原曲起点、跳到哪）是那首曲子自己的小节，
第 1 小节 = 素材表里写的「第 1 小节（秒）」。两种位置各数各的，四首的第 1 小节不用对齐。

## 1 开头

```markdown
# 这套 set 的名字

- 规范：v5
- 主速：132
```

`主速` 是全场从头到尾的 BPM；中间要变速就另写一张「速度」表（第 3 节），两者写一个就行。

## 2 素材

曲库里的一份音频 = 一份素材。同一份素材可以被多个片段用。

```markdown
## 素材

| ID | 曲名 | 文件名 | 原 BPM | 第 1 小节（秒） | 小节数 | 调性 |
|---|---|---|---|---|---|---|
| A1 | Opening Theme — Artist One | 01 Opening Theme.mp3 | 132 | 0.250 | 176 | 8A |
| A3 | Perc Loop 16 | perc_loop_16.mp3 | 132 | 0.000 | 16 | — |
```

| 列 | 必写 | 说明 |
|---|---|---|
| ID | 是 | `A1`、`A2`…（字母数字，谱里不重复） |
| 曲名 | 是 | 写「曲名 — 艺人」时，「—」后面的当艺人 |
| 文件名 | 是 | 相对谱所在文件夹的路径；导入时按它取文件 |
| 原 BPM | 是 | 这首自己的速度（整首不变速） |
| 第 1 小节（秒） | 建议 | 第 1 小节第 1 拍在文件的第几秒；不写就用分析出来的 |
| 小节数 | 建议 | 用来核对网格、检查片段有没有读过曲尾 |
| 调性 | 否 | 只显示 |

## 3 速度（可以不写）

```markdown
## 速度

| 全场位置 | BPM | 变化 |
|---|---|---|
| 1.1 | 132 | |
| 97.1 | 132 | 保持 |
| 113.1 | 134 | 渐变 |
```

第一行从 `1.1` 起。`变化`：`渐变` = 从上一行匀速变到这一行；`跳变`（或空着、`保持`）= 到这一拍一下换过去。
全场只有这一张速度图：每台 Deck 的速率 = 图上的 BPM ÷ 素材的原 BPM，Echo、Roll 的拍长也跟它走。

## 4 片段

片段 = 「哪份素材、放在哪台 Deck、从原曲哪里开始、全场哪一拍起播、哪一拍停」。

```markdown
## 片段

| ID | 素材 | Deck | 原曲起点 | 全场起播 | 全场停止 | 角色 | 推子 | LOW | MID | HIGH | Filter | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| C1 | A1 | D1 | 1.1 | 1.1 | 129.1 | 主曲 | 10 | 12点 | 12点 | 12点 | 关 | 开场曲 |
| C3 | A3 | D3 | 1.1 | 33.1 | 81.1 | 节奏层 | 6 | 7点 | 12点 | 12点 | 关 | 打击乐循环 |
```

| 列 | 必写 | 说明 |
|---|---|---|
| ID | 是 | `C1`、`C2`… 同一份素材再用一次 = 新的片段 ID |
| 素材 | 是 | 素材表里的 ID |
| Deck | 是 | `D1`–`D4`。同一台 Deck 上的片段不能重叠：后一个要在前一个停下以后才装得上 |
| 原曲起点 | 否 | 原曲的小节.拍，默认 `1.1` |
| 全场起播 | 是 | 全场位置 |
| 全场停止 | 否 | 全场位置；写 `播完`（或空着）= 放到这首的曲尾 |
| 角色 | 否 | 主曲 / 进曲 / 出曲 / 节奏层 / 声线 / 待命…（不会自动改旋钮）。**主曲 / 进曲 / 出曲 = 主线**（这一首歌），别的 = 工具（加在上面的循环、人声…）：界面按它分粗细，主线上一首接一首的地方标成「主要的交接」（第 13 节） |
| 推子、LOW、MID、HIGH、Filter | 否 | 起播时旋钮的位置。默认推子 10、EQ 12 点、Filter 关 |
| Key Lock | 否 | `开` / `关`（默认关） |
| 准备 | 否 | 起播前多久装好、摆好旋钮（时长）。默认约 4 秒，最少 1 秒 |
| 备注 | 否 | |

### 旋钮位的写法（Denon Prime 4+ 面板上的说法，和 v4 一样）

| 旋钮 | 写法 |
|---|---|
| LOW / MID / HIGH | 钟点位 `7点`（切到底）…`12点`（不动）…`5点`（推满），可以写半点 `10点半`；或直接写 `-6dB`；`切` = 7 点 |
| Filter | `关`（中间）；`左9点`（低通方向）、`右3点`（高通方向）；对不上钟点的写 `左62%` |
| 推子 | `0`–`10`，可以写小数 |

## 5 场景

场景把全场分成几段，每段写清楚「为什么这么做」。图、动作提示、交接说明显示的是同一份说明。

```markdown
## 场景 3：换节奏，保留旧主题（81.1 – 129.1）

- 作用：第二首接管节奏，第一首的主题多留 16 小节再走
- 保留：D1 的主题（MID）
- 前景：第 97 小节以后是 D2
- LOW：第 97 小节第 1 拍同一拍对换
- MID/HIGH：旧主题走完以前不退 D1 的 MID
- 角色：D1 出曲，D2 进曲
- 有意：中频叠加
```

| 项 | 说明 |
|---|---|
| 作用 / 保留 / 前景 / LOW / MID/HIGH | 正式场景这五项都要写。还没想好的场景写 `- 状态：草稿`，缺的项显示成「待补充」 |
| 角色 | `D1 主曲，D3 节奏层`：这个场景里每台 Deck 是什么角色 |
| 有意 | `多低频` / `两条声线` / `中频叠加`：告诉程序这是有意安排的，对应的提示不再出现 |
| 说明 | 随便写 |

程序会提示「同时有两个低频没切」「两条声线叠在一起」之类的地方，但它只看得到旋钮位、看不到实际的声音，所以这些是**提示**，不是错误，不会拦着不让演出。

场景里（或者全场任何一个 `##` 下面）可以写下面三种表。

## 6 参数表：任何时候都能动旋钮

标题是 `### C1 参数`（片段 ID + 「参数」）。**写在哪个场景、哪一拍都行，独奏的时候一样能写**——v4 只能在过渡里动旋钮，v5 没有这个限制。

```markdown
### C1 参数

| 位置 | Filter | 说明 |
|---|---|---|
| 25.1 | 保持 | 开始往右拧高通 |
| 32.4 | 右3点 | |
| 33.1 | 跳 关 | 落地：Filter 一下回中 |
```

列：`位置`（全场位置）+ `LOW` `MID` `HIGH` `Filter` `推子` 里用到的几个 + `说明`。每一格三种写法，曲线的形状是写明的，程序不猜：

| 这一格写 | 意思 |
|---|---|
| `保持` | 到这一拍为止不动（= 从这里开始动手的起点） |
| 直接写值（`11点`、`7`、`右3点`） | 从这张表里这个旋钮的上一行**匀速拧到**这个值，这一拍到位 |
| `跳 7点` | 这一拍**一下到位** |
| 空着 | 这一行不管这个旋钮 |

一张表里某个旋钮第一次出现就直接写值，程序不知道从哪一拍开始拧，会报错并告诉你怎么改：在开始动手的那一拍加一行写 `保持`，或者写成 `跳 …`。
同一个片段的同一个旋钮可以在几张表里接着写（各场景写各场景的），但两段不能重叠。

## 7 Loop 与跳段

```markdown
### Loop 与跳段

| 片段 | 位置 | 做什么 | 说明 |
|---|---|---|---|
| C3 | 33.1 | loop 4小节，到 81.1 出 | 四小节打击乐一直转 |
| C5 | 173.1 | loop 2小节 同起点，到 175.1 出 | loop 越来越短 |
| C1 | 65.1 | loop 8拍 × 4 | 转四遍 |
| C2 | 97.1 | 跳到 49.1 | 跳到原曲第 49 小节 |
```

| 做什么 | 意思 |
|---|---|
| `loop 2小节，到 161.1 出` | 在「位置」那一拍打 loop，圈的起点 = 那一拍正在放的原曲位置；到全场 161.1 出圈，从圈尾接着往下放 |
| `loop 8拍 × 4` | 转 4 遍后出 |
| `loop 2小节 从原曲 17.1，到 …` | 圈的起点另指定 |
| `loop 1小节 同起点，到 …` | 和上一个 loop 用同一个起点（把 loop 越收越短） |
| `跳到 97.1` | 这一拍跳到原曲 97.1 接着放（全场位置不变） |

loop 最短 1/8 拍。全场位置照常往前走，只有这个片段读原曲的位置在绕圈；别的片段不受影响。

## 8 效果

```markdown
### 效果

| ID | 类型 | 路由 | 目标 | 开始 | 结束 | 参数 | 说明 |
|---|---|---|---|---|---|---|---|
| F1 | Echo | 发送 | C4 | 52.1 | 53.1 | 拍长 1/2拍；送出 1/2；反馈 0.6 | 句尾送进回声 |
| F4 | Roll | 插入 | C3 | 76.1 | 77.1 | 频段 HIGH；拍长 1拍 → 1/2拍 → 1/4拍 | 越切越碎 |
```

参数用分号隔开，每个是「名字 值」；量可以写 `1/2`、`0.5` 或 `50%`；写 `a → b` 的是在开着的这一段里匀速变过去。
送出 / 返回中间要停、要拐弯的，在值后面写到哪一拍为止：`返回 0 → 1/2@144.4` = 到 144.4 走到 1/2，之后保持；`→ 跳 0@146.1` = 那一拍一下到。

### 8.1 路由：声音怎么走

| 路由 | 目标怎么写 | 干声和效果声 | 给谁用 |
|---|---|---|---|
| `发送` | 一个片段 `C4` | 原通道的干声照常出一次；另送一份（推子之后的）进效果，返回里只有效果声 | Delay / Echo / Reverb |
| `插入` | 一个片段 `C3` | 这个片段的声音整个经过处理，没有另一条干声。处理在通道 EQ / Filter 之后、推子之前 | 现场效果 |
| `组插入` | 几个片段 `C1+C3` | 这几个片段各自过完推子以后加在一起处理，它们不再各自直通 | 现场效果 |
| `总输出` | 写 `总输出` | 处理整个主混音（包括效果返回和采样）。只有谱上明确这么写才会用 | 现场效果 |

同一条路由 + 同样的目标 = 同一个**处理组**。规则：

- 同一时间一个片段最多在一个处理组里；两个处理组先后用同一个片段，中间至少隔 1 拍。
- 总输出在处理的时候，别的处理组不能同时开着。
- 一个处理组里同一种效果一次开一个；不同的效果可以叠，按固定顺序走：分频段的 Trans / Roll → 整路的 Trans → Roll → Filter → Flanger → Phaser → Spiral → Echo → Noise → Release。
- 每个片段另外可以有自己的 Delay / Echo / Reverb 发送，互不影响；发送取的是处理组之后、推子之后的声音。
- 片段停了以后它的尾音照样响完，但不会收到同一台 Deck 后来装的新片段的声音。

### 8.2 发送效果（DJ 常用的三种）

| 类型 | 参数（默认） |
|---|---|
| `Delay` | 拍长（1/2拍）、反馈（0 = 只回一次）、乒乓（0）、送出（1）、返回（1）、尾音 |
| `Echo` | 拍长（1/2拍）、反馈（0.7）、乒乓、送出、返回、尾音 |
| `Reverb` | 衰减（0.5）、带宽（1）、阻尼（0）、送出、返回、尾音 |

每个效果有自己的实例（自己的缓冲和尾音），同时最多 8 个（还在响的尾音也算）。`尾音 2小节` = 关掉送出以后尾音留多久，不写就按反馈 / 衰减算。

### 8.3 现场效果（走插入 / 组插入 / 总输出）

| 类型 | 参数（默认） | 做什么 |
|---|---|---|
| `Trans` | 频段（全部）、周期（1/2拍）、占空（1/2）、深度（1） | 跟拍的门：每个周期前「占空」这一段开着，其余压低「深度」。只切选中的频段，别的频段照常 |
| `Roll` | 频段（全部）、拍长（1拍，可以写 `1拍 → 1/2拍 → 1/4拍`）、混合（1） | 在「开始」那一拍抓一段，原地反复放到「结束」；写了几段拍长就在这段时间里平均分、越放越碎 |
| `Filter` | 模式（高通 / 低通 / 带通）、截止（必写，`200Hz → 4kHz`）、共振（0.7） | 一个可以扫的滤波器 |
| `Filter Echo` | 模式、截止（必写）、共振、拍长（1/2拍）、反馈（0.6）、送出（1）、返回（1）、尾音 | 宏：滤波 + 回声一起（退出旧曲、准备段）。展开成组里的两件，图上看得到 |
| `Spiral` | 拍长（1/2拍）、音高（+12，半音）、反馈（0.7）、混合（1/2）、尾音（4拍） | 回声一圈一圈往上（或往下）滑 |
| `Noise` | 音量（`0 → 1/4`）、频率（`400Hz → 8kHz`）、共振（1.5） | 加一层扫频的噪声（上行 / 下行）。它不是原曲里的声音，图上会标出来 |
| `Flanger` | 周期（1小节）、深度（0.7）、反馈（1/2）、混合（1/2） | 梳状扫频，相位跟拍 |
| `Phaser` | 周期（1小节）、深度（0.7）、反馈（1/2）、混合（1/2） | 陷波扫频，相位跟拍 |
| `Release` | 方式（`Echo` / `刹车` / `回转`，必写）、收尾（`回原声` / `退场`，必写；可以只写这两个字）、拍长（1/2拍，只有 Echo 方式有）、反馈（0.6，只有 Echo 方式有） | 收掉这一组正在做的效果，见 8.4 |
| `采样` | 重复（不写 = 打一下）、音量（0.8） | 「目标」写音源，见 8.5 |

`频段` 写 `LOW`、`MID`、`HIGH` 或用 `+` 连起来（`MID+HIGH`）。这是按频率分的三段（分频点 250 Hz 和 2.5 kHz），不是把鼓、贝斯、人声分开。

### 8.4 Release 到底做了什么

Release 写和要收的那一组同样的路由、同样的目标，只收那一组，别的 Deck 不受影响。

1. 「开始」那一拍：这一组还开着的效果到此为止，之后也不会被原来的安排重新打开；这一组的干声在这一拍收掉。
2. 「开始」到「结束」之间放 Release 自己的声音：`Echo` = 开始前最后一个拍长的声音带着反馈转（最多响到「结束」，最后一段淡掉）；`刹车` = 像唱盘断电一样慢下来（最长 8 秒）；`回转` = 倒着甩回去（最长 2 秒）。
3. 「结束」之后：`回原声` = 回到这一组现在的干声（不会让已经停的片段复活，也不动 EQ / Filter / 推子）；`退场` = 这一组保持静音，直到这一组下一条效果开始，或者片段停。

### 8.5 采样

```markdown
| F5 | 采样 | 采样 | snare | 80.3 | 81.1 | 重复 1/4拍；音量 0.6 | fill |
```

「目标」写音源：内置的 `kick` `snare` `clap` `hat` `openhat` `rim` `tom` `crash`，或者谱旁边的一个短音频文件名（最长 8 秒）。
从「开始」起每隔「重复」打一下，到「结束」那一拍还在响的全部收掉（不会自动补满）。一份谱最多 8 种采样，同时最多 4 个在响；两组采样不能重叠。采样直接进主输出。

## 9 程序会检查什么

**错误**（不改就不能演出，都带行号和怎么改）：看不懂的版本 / 类型 / 位置；片段读过了曲尾；同一台 Deck 上片段重叠或者来不及装；
同一个旋钮两段重叠；直接写值但不知道从哪开始拧；效果的目标不存在、路由不对、参数超出范围；处理组冲突；引擎没有这个能力（会说缺的是哪一种）。

**提示**（可以演出）：多个低频 / 声线 / 中频主题叠在一起；没用到的素材；Key Lock 的延迟没有补偿；存谱时的效果版本和现在的引擎不一样；
要放的素材没写元素表（第 14 节）。

## 10 和旧谱的关系

- v1–v4 的谱不用改，直接能放；它们在界面上也能看成四 Deck 的图（A/B 两台交替用 D1 / D2）。
- 旧谱可以「另存为 v5 的谱」，得到一份新文件（原来的不动），里面每个旋钮动作都写成了上面的显式写法。
- 用了三台以上 Deck、场景效果的 v5 谱不能存回 v4。

## 11 交付

「导出演出包」生成一个文件夹：谱（.md）和用到的全部原曲、采样文件在同一层，文件名和内容原样（不转码，不生成混音）。
换一台电脑，把整个文件夹拖进 DJ Studio 就能用；里面的清单（`djstudio-package.json`）记着每个文件的哈希，对不上的会指出是哪一个。

## 12 Hot cue（自动标出来的点）

谱里不用写 hot cue：程序按这套谱算出每份素材的 8 个打击垫（Denon Prime 4+ 的 HOT CUE 1–8），画在演出画面上「整首曲子」的波形和滚动波形上，
并导出「Hot Cue 表（Prime 4+）」——照着在 Engine DJ 或机器上设。规矩和两 Deck 的谱是同一套（[SET_SPEC.md](SET_SPEC.md) 第 7 节：
**打击垫没有固定用途**，放的是这份素材在这套谱里要用到的点；颜色、名字的取法、放不下时先留谁都一样）。v5 没有「过渡」，点从片段来：

| 名字 | 什么时候放 |
|---|---|
| IN | 片段从原曲这里起播。起播时不在 12 点的旋钮写在注释里 |
| BASS IN / BASS OUT / HPF / LPF / FILTER OFF / EQ UP / EQ DOWN / MID UP … / FADER UP / FADER DOWN | 这个片段的旋钮 / 推子开始拧，或一下拧到位（同一拍开始的几个动作是一个点） |
| 效果的名字（下表）、发送效果关掉时「… OFF」 | 落在这个片段上的效果开 / 关 |
| OUT | 主线上的交接从这里开始：下一首进来的那一拍，这一首读到的地方（红）。进来的那一首，IN 的注释里写接的是谁、哪一拍换低频 |
| LOOP n | 圈头（n = 圈长的拍数）。片段在圈里停的，不另放 STOP，写在注释里 |
| JUMP n | 跳段：跳到的那一小节 |
| STOP | 片段在原曲这里停 |

- 位置 = 原曲上的小节（素材自己的 1.1 起），落在整拍上；按在原曲上的先后从 1 号垫排。
- 同一份素材被几个片段用到（同一句人声放两次）：几个片段的点合在一起。同一个位置只占一个垫子（留要按的：IN > JUMP > LOOP > OUT > STOP），别的写进注释。
- 超过 8 个：先留 IN / OUT / JUMP / LOOP / STOP，再留效果和换低频（BASS IN / BASS OUT），别的旋钮点按先后。
- 素材上本来就有的垫子（旧 set 另存成 v5 时带过来的）不动；它们标过的位置不再重复放。

## 13 主线、工具和主要的交接

四台 Deck 同时放的时候，不是每一条轨道都是「一首歌」。程序按角色把片段分成两类（只是分类，不改声音）：

- **主线**：角色是 主曲 / 进曲 / 出曲 的片段（片段表里写的，或者场景的「角色」里给这台 Deck 写的）——这一首歌。
- **工具**：别的角色（节奏层、声线…）——加在主线上面的打击乐循环、一句人声之类。
- 哪里都没写角色的片段：有 16 小节以上直着放的一段、而且 LOW 不是从头切到尾 → 主线；只转 loop 的、很短的、LOW 一直切着的 → 工具。
  想自己定，就在片段表或场景里把角色写上。

**主要的交接** = 主线按起播的先后一首接一首：从下一首起播（进来）到上一首停（交出去）。换低频的那一拍 = 下一首的 LOW 从切着放进来的那一拍
（没有就看上一首的 LOW 切掉的那一拍）。两首没有叠着放的 = 直接接上。

界面上：整套 set 的安排里主线是粗的色块、工具是细的，交接是橙色的一段、换低频是一条蓝线；每一行、每个通道都写着「主线」或「工具」；
头上写着现在在哪一次交接里、还有几小节换低频、几小节交完。Hot cue 里出曲的 OUT 就放在交接开始的地方。

## 14 元素表（建议写）

每份素材里各个声部——kick、bass、拍手、镲、合成器、人声……——在**原曲的哪几小节**有、有多满。程序不分析声音，这张表要你（或者做 set 的时候
用的工具）给。有了它，演出画面的 EQ 曲线底下每台 Deck 画一张格子图：一行一个声部、一格一小节，格子的深浅 = 这个声部**过完旋钮以后**
还剩多少；旋钮的线叠在格子上。于是「为什么在这里切低频、退高频」一眼看得出来——对面的 kick 进来了，这边的 kick 就该没了。

```markdown
## 元素

| 素材 | 元素 | 原曲小节 |
|---|---|---|
| A2 | kick | 25–72，97–168 |
| A2 | bass | 25–72 中，97–168 |
| A2 | 闭镲 | 1–72 中，97–192 中 |
| A2 | 人声 | 121–128，137 弱 |
```

也可以一份素材一张表：标题写 `### A2 元素`，表里就不用「素材」这一列了。

- **原曲小节**：这份素材自己的小节（第 1 小节 = 素材表里的「第 1 小节（秒）」），不是全场小节。片段从哪里起播、转不转 Loop、跳不跳段，
  程序自己会对上——同一份素材被几个片段用，只写一遍。
- 一项写「从第几–到第几」，两头都算（`25–72` = 第 25 到第 72 小节）；只有一小节就写一个数（`137`）。几项之间用逗号、顿号或分号隔开。
- **有多满**写在后面：`满` / `中` / `弱`（不写 = 满）；想写细一点可以写 0–1 的小数或百分数（`0.8`、`45%`）。没有这个声部的小节不用写。
- 同一份素材的同一个声部只写一行；一个小节不能写两遍。
- 这张表只管画图，不影响声音；不写也能演出（会提示一句，画面上那一台就没有格子）。

认得的声部（画面上从上到下就是这个顺序）和它们主要在哪个频段——「过完旋钮还剩多少」就按这个份额算（画图用的约数：
kick 不全在低频，所以切了 LOW 格子还剩一点点）：

| 元素 | 还可以写成 | LOW | MID | HIGH |
|---|---|---|---|---|
| kick | 底鼓、大鼓 | 0.80 | 0.15 | 0.05 |
| bass | 贝斯、低音、sub | 0.85 | 0.15 | 0.00 |
| 拍手 | clap、军鼓、snare | 0.00 | 0.60 | 0.40 |
| 闭镲 | 镲、hat、hihat、hi-hat、开镲、踩镲 | 0.00 | 0.10 | 0.90 |
| ride | 叮叮镲、crash、吊镲 | 0.00 | 0.20 | 0.80 |
| 打击 | perc、打击乐、通鼓、tom | 0.15 | 0.55 | 0.30 |
| 合成器 | synth、旋律、lead、主音、stab、琶音、arp | 0.10 | 0.65 | 0.25 |
| 铺底 | pad、氛围、和弦、chord | 0.15 | 0.65 | 0.20 |
| 人声 | vocal、vox | 0.05 | 0.75 | 0.20 |
| 音效 | fx、噪声、riser、sweep | 0.05 | 0.35 | 0.60 |

过完旋钮还剩多少 = 有多满 ×（LOW 的份额 × LOW 旋钮放过去多少 + MID 的 + HIGH 的）× Filter 放过去多少 × 推子。
旋钮 12 点 = 全放过去，7 点（切）= 一点不剩，中间按分贝算；往右拧的 Filter 先吃掉低频，往左拧先吃掉高频。
